# Key functionalities

- Enable user to upload data. User should be able to upload a .clf file or upload a previous run for comparison

- Enable user to save data and runs. User should be able to add notes and setup sheets to the raw data before it is all saved together locally with a custom name (session name and run number)

- Enable user to attach setup sheets and notes to runs. Editable setup sheets for both electrics and setup

- Allow data comparisons between different runs. allow lap comparisons between runs along with setup sheet differences
